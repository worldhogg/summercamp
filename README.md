### MyString
Собственная реализация строкового класса — упрощённый аналог `std::string`.
- **RAII** — захват ресурса в конструкторе, освобождение в деструкторе
- **Правило пяти** — деструктор, копирующие и перемещающие конструктор и оператор присваивания
- **Move-семантика** — `noexcept`-операции перемещения
- **Copy-and-swap** — безопасное присваивание с защитой от самоприсваивания
- **Перегрузка операторов** — `[]`, `<<`, `==`, `!=`, `+`

```bash
cd my_string
cmake -B build
cmake --build build
./build/my_string
```

### Text RPG
Консольная ролевая игра — практика ООП-проектирования.
- **Иерархия наследования** в два уровня: `Character` → `Monster` → `Goblin` / `Dragon`, а также `Hero`
- **Полиморфизм** — боевая система работает через указатели на базовый класс
- **Абстрактные классы и чисто виртуальные функции** — единый интерфейс персонажей
- **Виртуальный деструктор** — корректное освобождение через базовый указатель

```bash
cd rpggame
cmake -B build
cmake --build build
./build/rpggame
```

---

### MyVector
Собственная реализация динамического массива-шаблона — упрощённый аналог `std::vector`.
- **Шаблоны** — контейнер для произвольного типа `T`
- **Rule of Five** и семантика копирования / перемещения
- **Реаллокация** буфера при росте, работа с сырой памятью
- **Итераторы** для обхода в диапазонном `for`

```bash
cd myvector
cmake -B build
cmake --build build
./build/myvector
```

### weekBest
Система выбора «Игрока недели» футбольной лиги — первый проект с упором на
**проектирование архитектуры**, а не на алгоритм.
- Классы игроков, статистики тура и лиги с чётким разделением ответственности
- Сбор статистики за тур и расчёт лучшего игрока по заданным правилам
- Отделение бизнес-логики от данных

```bash
cd weekBest
cmake -B build
cmake --build build
./build/weekBest
```
